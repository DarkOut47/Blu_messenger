# <b>BLEmess</b>

BLEmess — это Android-приложение для обмена сообщениями и файлами через Bluetooth без подключения к интернету. Оно создано для ситуаций, когда обычная сеть недоступна, но нужно быстро отправить текст, изображение или другое содержимое между устройствами рядом. 

##Представим ситуацию то что это приложение скачал каждый человек в твоем городе в плотности до 10 метров, и теперь даже без обходов, VPN и даже интернета ты сможешь написать "Привет" другу за километры. Каждый пользователь приложения выполняет роль Роутера для обмена Сообщениями для других пользователей!

## Зачем это нужно

- обмен сообщениями между устройствами без интернета;
- работа в локальной сети через Bluetooth;
- удобный способ передавать данные в местах с плохой связью;
- простой интерфейс для быстрого общения между соседними телефонами.

## Как это работает

Приложение использует Bluetooth-соединение для поиска доступных устройств рядом и запуска обмена данными между ними. После подключения пользователь может:

- отправлять текстовые сообщения;
- передавать изображения;
- обмениваться файлами между телефонами;
- использовать приложение в локальной среде без интернет-подключения.

## Основные возможности

- поиск устройств по Bluetooth;
- подключение к соседнему устройству;
- отправка сообщений;
- передача изображений;
- работа без интернета и внешних серверов.

## Пример сценария использования

Когда рядом находятся два телефона, приложение автоматически обнаруживает их через Bluetooth. После соединения можно быстро отправить сообщение или картинку без нео��ходимости использовать Wi‑Fi, мобильный интернет или облачные сервисы.
